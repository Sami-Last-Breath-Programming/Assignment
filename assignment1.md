<h2> Write a one-paragraph explanation of what happens between typing a URL and seeing the page. </h2>
<h3> 
  When we type a url: 
  <pre style="padding-top:20px;"><code> https://www.google.com </code> </pre>
  First the domain name of the url is converted into Ip Address of the server <br>
  <div style="margin-top:15px; padding: 5px; background-color: yellow; width: fit-content; font-weight:bold;"> This process Steps </div> <br>
  <ol>
    <li> User typed the domain name of the website. </li>
    <li> DNS resolves the Ip Address of the website </li>
    <li> Browser sent http request to the server. </li>
    <li> TLS Handshake is done and connection is secured. </li>
    <li> Browser sents request with <p style="font-weight:bold; display:inline;"> Method, Header and Body .</p> </li>
    <li> Server process the request and send data back with <p style="font-weight:bold; display:inline;"> Success Code, Header, Body(containing html, css and js) </p> </li>
    <li> Browser process the responce and display the webpage.


</ol>  
</h3>
